# 00-raw — Inbox docs thô

Nơi BA ném vào **nguyên trạng**, chưa biên dịch:

- Docs nghiệp vụ thô (`.md`, `.docx`, `.pdf`, ảnh, ghi chú họp…)
- Link / export Figma
- Ảnh chụp màn hình, sketch

Skill `compile-feature` của Claude sẽ đọc thư mục này + Figma (qua Figma MCP) để sinh
`01-business-spec.md` và `02-design-spec.md`. **Không xoá** raw sau khi biên dịch —
giữ để truy vết và biên dịch lại khi nguồn đổi.
